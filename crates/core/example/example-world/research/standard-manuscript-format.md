# Standard Manuscript Format

The layout publishers have traditionally asked for: double-spaced, in a plain typeface, with the author's name and the page number on every page. A manuscript page is usually reckoned at about 250 words.

This is a research note: something true in the real world, with its source. Story Time's page estimates use 250 words a page, which you can change in `.story-time/config.toml`.
