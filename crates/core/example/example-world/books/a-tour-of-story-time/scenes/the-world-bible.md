# The World Bible

Everything that isn't a scene goes in the world bible, which every book set in this world shares.

The Writer is a character note: who someone is, how they look and speak, and what they want. The Binder is a location note, for a place where things happen. The Writing Log is a world note, for how the world works and what it costs. The timeline lists what happened when, including what no scene shows.

A scene links to a note with double square brackets, like this: [[the-writing-log|The Writing Log]]. If a link leads to no note yet, Check offers to create one.

Research holds what's true in the real world, with its source. The scratchpad keeps fragments that belong to the world but not yet to a book.
